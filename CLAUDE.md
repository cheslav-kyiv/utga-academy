# Академія ГС «ВАГ» — правила для роботи з репозиторієм

## Термінологія (обов'язково)

- **Ніколи не пишемо «екскурсовод»** — у курсах, сертифікатах, бейджах, документації, коді та повідомленнях.
- Пишемо **«туристичний гід»**. За видами туризму — **«гірський гід»**, **«музейний гід»**, **«гід по території»** (національного парку, заповідника, заказника тощо) тощо.
- Слово «екскурсія» як назва формату заходу допустиме.
- Нова заміна термінів у вже наявних текстах Moodle — через `config/site.json` → `terminology.replacements` (застосовує `provisioning/provision.php` без перезбирання курсів).

## Формулювання результатів навчання

- На сертифікатах: «курс **підвищення кваліфікації**» (рішення ГС «ВАГ»).
- «Qualification Validated» / «кваліфікацію підтверджено» не використовуємо, доки немає затвердженої процедури присвоєння чи визнання кваліфікації уповноваженим органом. Для курсів з оцінкою експерта — «Learning Outcomes Assessed» / «результати навчання оцінено».
- ЄКТС не вказуємо без формального партнерства з акредитованим ЗВО.
- ESCO URI — лише верифіковані з ESCO Portal; інакше `uri: null`.

## Робота з курсами

- Джерело змісту — `courses/*/course.json` і `questions.gift`; `--rebuild` видаляє прогрес слухачів (викладачі зберігаються) — не застосовувати до курсів, які вже проходять.
- На сервері (adm.tools) PHP у консолі — `php8.3`, не `php`.
