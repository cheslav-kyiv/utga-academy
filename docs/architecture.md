# Архітектура

## Шари

| Шар | Технологія | Статус |
|---|---|---|
| Навчальне ядро (LMS) | Moodle 4.5 LTS, тема Boost (стандартна) | 🟢 перевірено локально |
| PDF-сертифікати | `mod_customcert` (GPL v3), гілка `MOODLE_404_STABLE`, протестована на 4.5.15+ | 🟢 перевірено локально |
| Цифрові бейджі | Вбудовані бейджі Moodle, Open Badges 2.0 (hosted verification) | 🟢 перевірено локально |

| Портал ГС «ВАГ» (React/Vite) | Каталог, профілі гідів, публічний реєстр | 🔵 заплановано (етап 2) |

## Чому зміст у Git, а не лише в інтерфейсі Moodle

- **Відтворюваність:** курс можна повністю перезібрати на новому сервері однією командою.
- **Рецензування:** зміни змісту видно в pull request (хто, що, коли змінив) — важливо для експертного затвердження.
- **Резервна копія структури** незалежно від бази даних.

Після публікації курсу дрібні правки можна робити й в інтерфейсі Moodle, але тоді `--rebuild` їх перезапише. Правило: **джерело правди — репозиторій**.

> ⚠️ `--rebuild` видаляє курс разом з даними слухачів. На робочому сайті використовувати лише до запуску курсу або для нових курсів.

## Логіка курсу (як на umir.com.ua, але відкритими засобами)

```
Розділ 0: «Про курс»
   ↓ (переглянуто)
Модуль 1: відеолекція + посібник
   ↓ (переглянуто останній елемент)
Модуль 2 … Модуль N
   ↓
Фінальний етап:
   Підсумковий тест (≥ 80%, спроби не обмежені, правильні відповіді не показуються)
      ↓ (складено)
   Анкета зворотного зв'язку (анонімна)
      ↓ (надіслано)
   PDF-сертифікат (код + QR) ──→ публічна перевірка /mod/customcert/verify_certificate.php
Завершення курсу (усі елементи) ──→ автоматична видача бейджа Open Badges 2.0
```

Усе це реалізовано **стандартними механізмами Moodle**: «Обмеження доступу» (availability_completion), «Виконання діяльності», «Завершення курсу», «Бейджі». Жодного власного плагіна — менше ризиків при оновленнях.

## Відмінності від платформи Moco (umir.com.ua)

| Moco | Академія ГС «ВАГ» | Примітка |
|---|---|---|
| Комерційна тема `boost_moco_v3` | Стандартна тема Boost | Можна додати фірмовий стиль окремо |
| Анкети за «тегом користувача» | Поле профілю «Категорія слухача» + `availability_profile` | Поле створюється; умовні анкети — за потреби |
| Сертифікат | `mod_customcert` + бейдж Open Badges | Бейдж дає машинно-перевірюване підтвердження |
