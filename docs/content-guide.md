# Як редагувати зміст курсів

Кожен курс — тека в `courses/` з двома файлами.

## `course.json`

| Поле | Що це |
|---|---|
| `shortname` | Унікальний шифр курсу, напр. `UTGA-G02`. Не змінюйте після запуску |
| `fullname` | Повна назва курсу (є в сертифікаті) |
| `category` | `UTGA-GUIDES` або `UTGA-HOSPITALITY` (див. `config/site.json`) |
| `hours` | Обсяг в академічних годинах (є в сертифікаті) |
| `summary_html` | Опис для каталогу та сторінки «Про курс» |
| `audience` | Для кого курс |
| `competences` | Прив'язка до ESCO: `label`, `uri` (лише перевірений URI з esco.ec.europa.eu, інакше `null`) |
| `references` | Стандарти й джерела |
| `modules[]` | Модулі: `title`, `summary_html`, `activities[]` |
| `final` | Тест, анкета, сертифікат, бейдж |

### Активності в модулі

**Відеолекція** (`"type": "video"`):

```json
{
  "type": "video",
  "name": "Відеолекція 1. …",
  "description_html": "<p>Про що відео</p>",
  "video_url": "https://…/lecture1.mp4",
  "captions_url": "https://…/lecture1.uk.vtt",
  "transcript_html": "<p>Повна текстова версія…</p>"
}
```

Без `video_url` показується повідомлення «Відео готується». **Субтитри (`.vtt`) і текстова версія обов'язкові** (WCAG 2.1 AA).

**Сторінка-посібник** (`"type": "page"`): поле `content_html`. У тексті використовуйте заголовки `<h3>`, списки `<ul>/<ol>`, `<strong>`.

## `questions.gift` — тест

Формат [GIFT](https://docs.moodle.org/en/GIFT_format): `=` — правильна відповідь, `~` — неправильна.

```
::G01-Q1:: Текст запитання? {
=Правильна відповідь
~Неправильна відповідь
~Ще одна неправильна
}
```

Прохідний бал — `final.quiz.pass_percent` (типово 80%). Оновіть текст `intro_html` тесту, якщо змінюється кількість запитань.

## Як застосувати зміни

1. Змінити файли, створити pull request, отримати затвердження експерта.
2. На сервері:

```bash
php -d max_input_vars=5000 provisioning/provision.php --moodle=/var/www/moodle --only=UTGA-G01 --rebuild
```

> ⚠️ `--rebuild` видаляє курс разом із прогресом слухачів. Для курсу, який уже проходять, правки вносяться в інтерфейсі Moodle **і** дублюються в репозиторій.

3. Новий курс: скопіювати теку існуючого курсу, змінити `shortname` і зміст, запустити `provision.php` без `--rebuild`.
